Literature Review: Data-Driven Academic Performance
Analysis System
Overview
This literature review compiles relevant research papers and resources across eight key
areas relevant to the Data-Driven Academic Performance Analysis System project. The
papers cover educational data mining, ML prediction models, document parsing with
LLMs, topic extraction, learning analytics dashboards, human-in-the-loop systems, and
explainability techniques.

KEY RESEARCH TAKEAWAYS FOR PROJECT
1. Document Parsing
Action: Use multimodal LLMs (Claude 3.5 Sonnet, GPT-4V) for syllabus and PDF
extraction
Why: Superior OCR-free document understanding with contextual awareness
Tools: pdfminer.six, PyPDF2 for baseline; LLM APIs for advanced parsing
2. Topic Extraction & Mapping
Action: Implement BERTopic for question-to-topic mapping with AI verification
Why: Better semantic coherence than LDA; integration with LLMs for automatic
interpretation
Consider: Human verification loop essential given ambiguous multi-topic questions
3. Performance Analytics
Action: Use OULAD dataset patterns for validation; implement SHAP/LIME for
explainability
Why: Rich benchmark for educational ML; transparent scoring crucial for student
trust
Model choice: Rule-based scoring (primary) + Random Forest/Linear Regression
(experimental)

Action: Design around actionable insights, not data overwhelming
Why: Learning analytics literature emphasizes clear, digestible visualizations
Key principle: Show topic-wise accuracy trends, consistency scores, personalized
recommendations
5. Human-in-the-Loop Verification
Action: Central to project architecture (student verifies AI topic mappings)
Why: Rich body of HITL research shows effectiveness in handling AI mistakes
Implementation: Simple approve/edit interface reduces friction
6. Recommendation Engine
Action: Personalize study recommendations using knowledge gaps + trends
Why: Growing research on knowledge graph-based paths and LLM-generated
recommendations
Approach: Identify weak topics, rank by impact, generate actionable guidance
